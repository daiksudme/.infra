## 機能: PRで変更を検証して統合する

管理者は、mainへの変更をレビューと必須検証を通してから統合できる。

### シナリオ: 所有者本人の変更を自動承認する

- 前提: daiksudがmainへのPRを作成し、Draftを解除した
- かつ: 最新コミットの必須検証がすべて成功した
- もし: 自動承認が実行される
- ならば: GitHub Actions BotがそのコミットをApproveする

### シナリオ: 未検証の変更を承認しない

- 前提: 必須検証が未完了、失敗、または現在のPRと異なるコミットを検証している
- もし: 自動承認が実行される
- ならば: Approveを投稿しない

### シナリオ: 他の投稿者の変更は所有者がレビューする

- 前提: daiksud以外がPRを作成した
- もし: 必須検証が成功する
- ならば: BotはApproveせず、daiksudのレビューを待つ

### シナリオ: mainへ直接変更しない

- 前提: mainにはPRとレビューと必須検証を要求するルールがある
- もし: 管理者またはBotがmainへ直接pushする
- ならば: GitHubが拒否する

Code Owner本人のPRに対するBotの承認が標準ルールを満たすことは、実PRで別途確認する。検証未完了をマージ可能と扱わない。
